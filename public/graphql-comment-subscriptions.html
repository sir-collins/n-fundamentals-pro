Live Song Comments — GraphQL Subscription

A demo of CommentsResolver's commentAdded subscription (Project 8 — GraphQL's version of WebSockets): the GraphQL counterpart to realtime-comments.html's Socket.IO demo, over the same underlying event. Enter a real song id, subscribe, then post a comment on that song from another window (Swagger UI at /api, or rest-client.http) — comments are still only ever created via REST, not GraphQL, so this page only listens.

Served from this same app, same origin as the ws://.../graphql endpoint it connects to — deliberately, since testing this against the hosted Apollo Sandbox (served over https://) runs into browser mixed-content blocking on the plain ws:// connection a local dev server exposes.
