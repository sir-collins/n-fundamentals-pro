# docs

Living documentation for this project, kept in sync as the app grows through
the learning roadmap below.

- [`00-roadmap.md`](./00-roadmap.md) — the full project-based NestJS learning
  path this app follows, project by project.
- [`01-progress.md`](./01-progress.md) — checklist of what's done, in
  progress, or not started yet, per project in the roadmap.
- [`02-commenting-standards.md`](./02-commenting-standards.md) — how we
  comment code in this project.
- [`03-journal.md`](./03-journal.md) — chronological build journal: what we
  did, why, and what tripped us up along the way. `01-progress.md` tracks
  *what's* done; this tracks *how* we got there.
- [`04-prisma-vs-typeorm.md`](./04-prisma-vs-typeorm.md) — Project 9's
  conclusion: the two ORMs compared from this app's own code, with the SQL
  each one actually sent and the mass-assignment bug the comparison found.

More numbered files appear here when a topic needs a reference document of
its own, rather than a journal entry.
